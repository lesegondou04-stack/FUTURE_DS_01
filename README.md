# Task 1: Business Sales Performance Analytics

## Executive Summary
This project analyzes business sales data to identify revenue trends, top-selling products, high-value categories, and regional performance to support data-driven decision-making.

##  Tools & Technologies Used
* **Python (Pandas, NumPy, Matplotlib, Seaborn)** for data generation, processing, and visualization.

##  Key Performance Indicators (KPIs)
* **Total Revenue & Units:** Tracked overall transactional sales volume.
* **Product Performance:** Identified top-tier products generating the highest revenue share.
* **Regional Breakdown:** Analyzed performance across regional markets to pinpoint high-growth areas.

##  Actionable Recommendations
1. **Target Regional Growth:** Focus marketing investments on top-performing regions to maximize return on ad spend.
2. **Inventory Optimization:** Ensure continuous supply for top-selling product categories to prevent stockouts.
3. **Sales Strategies:** Leverage insights on average order value to design bundling or cross-selling promotions.
